# 全聯福利中心 條碼快速查詢系統 (2026年10月最新版)

> 專為賣場補貨、上架、盤點、收銀核對與庫存管理打造的高效條碼查詢 APP。

---

## 🌟 系統特色與亮點

1. **完整收錄 202 款全聯休閒食品**
   - 包含卡迪那、可樂果、元本山、萬歲牌堅果、堅果飲/濃湯麵、年節禮盒與短銷促銷品。
   - 資料 100% 同步自官方最新 `全聯_條碼查詢_1010.xlsx` 檔案。

2. **多維度極速智慧搜尋**
   - **品名搜尋**：如輸入「洋芋片」、「海鹽」、「腰果」、「海苔」、「直麵」。
   - **貨架編碼**：如輸入「1-1-04」、「4-3-01」、「2-1」。
   - **全聯內部貨號**：如輸入「27010530」、「55430214」或後 4 碼。
   - **國際條碼**：如輸入「4710022062066」或後 6 碼。
   - **即時比對與關鍵字黃底高亮顯示**。

3. **POS 條碼槍螢幕掃描雙模強化**
   - **原廠標籤卡圖**：完整顯示全聯專屬貨架標籤排版格式與條碼圖。
   - **超清晰電子條碼 (SVG 向量)**：內建純原生 EAN-13 向量條碼生成引擎，零模糊、零鋸齒，確保 POS 條碼槍或手機相機 100% 一掃即過。
   - **螢幕調亮防反光**：一鍵開啟純白極致對比背景，徹底消除賣場日光燈反光。

4. **常用商品收藏 (⭐)**
   - 針對每日頻繁補貨或條碼容易污損的商品，可一鍵加為「常用」，固定於頂部專區隨時調出。

5. **相機即時掃碼 (📷)**
   - 支援手機相機對準條碼自動辨識，亦可上傳條碼照片或手動輸入。

6. **一鍵複製與列印手冊**
   - 一鍵複製「全聯貨號」、「國際條碼」或「完整商品資訊」。
   - 支援「列印條碼冊」功能，自動排版為 A4 紙本條碼手冊。

7. **100% 離線可用 (PWA 支援)**
   - 即使在賣場地下室或無網路環境也能瞬間秒開運行。

---

## 🚀 如何啟動使用？

### 方式一：直接雙擊開啟（最快速）
- 雙擊執行目錄下的 **`啟動全聯條碼APP.bat`** 或直接以瀏覽器開啟 **`index.html`** 即可立即使用！

### 方式二：啟動本機伺服器（支援 PWA 桌面安裝）
- 雙擊執行 **`啟動本機伺服器_PWA.bat`**。
- 瀏覽器會自動開啟 `http://localhost:8080/`。
- 在網址列右側點選「安裝全聯條碼」即可將本系統安裝為獨立電腦桌面或手機 APP！

## 🔄 未來更新條碼方法

若日後新增商品圖檔或更新 Excel 條碼表：
1. 將新圖檔放入對應品牌資料夾。
2. 於 PowerShell 執行目錄下的 **`.\scan_images.ps1`**。
3. 系統即會自動同步更新 `products_data.js` 與 `products.js`！
